# 🇨🇲 Discover Cameroon — Travel Website

A 5-page responsive travel website built with HTML5 and CSS3, showcasing
Cameroon as a tourist destination — "Africa in Miniature."

## Pages
- **Home** — welcome banner, introduction, and featured destinations
- **Destinations** — top attractions with images, descriptions, and Google Maps links
- **Things to Do** — activities by category with an image carousel, a top 10 list, and travel tips
- **Travel Packages** — pricing table comparing tour packages
- **Contact Us** — booking form, contact details, and an embedded map

## Features
- Semantic HTML5 (header, nav, main, section, footer)
- Shared CSS stylesheet across all pages
- CSS-only image carousel (no JavaScript)
- Responsive card layouts and styled table/form
- Embedded YouTube video and Google Map
