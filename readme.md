# Discover Cameroon Travel Website

A responsive static travel website promoting tourism in Cameroon. The project showcases destinations, activities, travel packages, and a contact form using HTML and CSS only.

## Overview

This website is designed for a tourism brand focused on Cameroon’s natural beauty, cultural diversity, and adventure experiences. It includes:

- a welcoming homepage
- destination highlights
- activity and sightseeing content
- travel package information
- a contact and inquiry section
- a consistent travel branding theme across all pages

## Project Files

- `index.html` – homepage and main landing page
- `destinations.html` – destination highlights and travel inspiration
- `activities.html` – things to do and experiences in Cameroon
- `packages.html` – package offers and itinerary information
- `contact.html` – booking and contact form
- `CSS/style.css` – shared styling and layout for the site

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- External images for travel content

## How to Run

1. Open the project folder in a browser directly, or
2. Serve the site locally using a simple HTTP server from the project root:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a static front-end website intended for design and presentation purposes. It does not include backend form processing or database integration.

## Submission Summary

The website is designed to feel cohesive, visually appealing, and travel-focused, with a warm Cameroon-inspired color palette and a clear content structure for tourism promotion.
